====== WHERE =====
filtrar por una condicion

===== ALL =====
verifica si todos los registros cumplen con la condicion

===== ANY =====
verifica si almenos un registro cumple con la condicion

===== CONTAINS =====
registros que "contengan" algo

===== ORDER BY - ORDER BY DESCENDING ===== 
odernar por algo 

==== TAKE - TAKE LAST =====
tomar solo un numero de resultados

===== SKIP =====
saltar un numero de resultados

===== SELECT =====
elegir resultados

===== LONGCOUNT - COUNT =====
numero de resultados que coinciden

===== MIN - MAX =====
menor y mayor dato

===== MINBY - MAXBY =====
resultado completo de quien tiene el menor o mayor datos

===== SUM =====
suma los resultados

===== AVERAGE =====
saca un promedio de los resultados

===== GROUP BY =====
agrupa los resultados por una key

===== LOOKUP =====
crea un diccionario con los resultados que cumplan la condicion 

===== JOIN =====
resultados que estan entre dos colecciones
